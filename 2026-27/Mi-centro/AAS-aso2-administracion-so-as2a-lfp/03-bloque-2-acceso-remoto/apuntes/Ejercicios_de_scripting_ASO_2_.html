Ejercicios de scripting ASO: .bat y bash

Actualizado: 13/11/2026

Cómo usar esta serie

La serie tiene 7 niveles y un proyecto final; cada ejercicio trae enunciado y solución en .bat (Windows, cmd) y en bash (Linux, WSL o Git Bash).

  • Ejecutar .bat: guarda el archivo como ejercicio.bat y lánzalo desde cmd: ejercicio.bat arg1 arg2.
  • Ejecutar bash: guarda el archivo como ejercicio.sh, dale permisos con chmod +x ejercicio.sh y lánzalo con ./ejercicio.sh arg1 arg2.
  • Orden: intenta cada ejercicio sin mirar la solución; cada nivel usa lo visto en el anterior.
  • Pruebas: ejecuta cada script con casos normales y con errores (sin argumentos, ficheros que no existen).
  • Seguridad: el nivel 5 crea usuarios y cierra procesos; hazlo en una máquina virtual, no en tu equipo real.

Nivel 1: primeros pasos

Objetivo: mostrar texto, usar variables y leer argumentos.

1.1 Hola, ASIR

Muestra por pantalla el mensaje Hola, ASIR.

.bat

@echo off
echo Hola, ASIR

bash

#!/bin/bash
echo "Hola, ASIR"

1.2 Saludo personalizado

Pregunta el nombre al usuario y salúdalo.

.bat

@echo off
set /p nombre=Como te llamas? 
echo Hola, %nombre%

bash

#!/bin/bash
read -p "Como te llamas? " nombre
echo "Hola, $nombre"

1.3 Suma de dos números

Recibe dos números como argumentos y muestra su suma.

.bat

@echo off
set /a suma=%1+%2
echo La suma es %suma%

bash

#!/bin/bash
suma=$(( $1 + $2 ))
echo "La suma es $suma"

1.4 Información del sistema

Muestra el usuario, el nombre del equipo y la fecha actual.

.bat

@echo off
echo Usuario: %USERNAME%
echo Equipo: %COMPUTERNAME%
echo Fecha: %DATE%

bash

#!/bin/bash

Nivel 2: condicionales y comprobaciones

Objetivo: tomar decisiones con if, validar argumentos y usar el código de salida de un comando.

2.1 Par o impar

Recibe un número como argumento y di si es par o impar.

.bat

@echo off
set /a resto=%1 %% 2
if %resto%==0 (echo Par) else (echo Impar)

bash

#!/bin/bash
if [ $(( $1 % 2 )) -eq 0 ]; then
    echo "Par"
else
    echo "Impar"
fi

2.2 ¿Existe el fichero?

Recibe una ruta y di si existe o no.

.bat

@echo off
if exist "%~1" (
    echo %~1 existe
) else (
    echo %~1 no existe
)

bash

#!/bin/bash
if [ -e "$1" ]; then
    echo "$1 existe"
else
    echo "$1 no existe"
fi

2.3 Validar argumentos

Si no se pasa ningún argumento, muestra el modo de uso y termina con código de error 1. Si se pasa, saluda.

.bat

@echo off
if "%~1"=="" (
    echo Uso: %0 nombre
    exit /b 1
)
echo Hola, %1

bash

#!/bin/bash
if [ $# -ne 1 ]; then
    echo "Uso: $0 nombre"
    exit 1
fi
echo "Hola, $1"

2.4 Calificación

Recibe una nota entera (0 a 10) y muestra Suspenso (menos de 5), Aprobado (5 y 6), Notable (7 y 8) o Sobresaliente (9 y 10).

.bat

@echo off
set /a nota=%1
if %nota% LSS 5 (
    echo Suspenso
) else if %nota% LSS 7 (
    echo Aprobado
) else if %nota% LSS 9 (
    echo Notable
) else (
    echo Sobresaliente
)

bash

#!/bin/bash
nota=$1
if [ "$nota" -lt 5 ]; then
    echo "Suspenso"
elif [ "$nota" -lt 7 ]; then
    echo "Aprobado"
elif [ "$nota" -lt 9 ]; then
    echo "Notable"
else
    echo "Sobresaliente"
fi

2.5 ¿Responde el equipo?

Recibe un nombre o IP y di si responde a un ping. Usa el resultado del comando, no su salida en pantalla.

.bat

@echo off
ping -n 1 %1 | find "TTL=" >nul
if %errorlevel%==0 (echo %1 responde) else (echo %1 NO responde)

bash

#!/bin/bash
if ping -c 1 "$1" > /dev/null 2>&1; then
    echo "$1 responde"
else
    echo "$1 NO responde"
fi

En Windows, ping puede devolver código 0 aunque el equipo no responda (por ejemplo, si el router contesta "host inaccesible"). Por eso la solución .bat busca TTL= en la salida.

Nivel 3: bucles

Objetivo: repetir acciones con for y while, y recorrer listas de valores.

3.1 Contar del 1 al 10

Muestra los números del 1 al 10, uno por línea.

.bat

@echo off
for /l %%i in (1,1,10) do echo %%i

bash

#!/bin/bash
for i in {1..10}; do
    echo "$i"
done

3.2 Tabla de multiplicar

Recibe un número como argumento y muestra su tabla del 1 al 10.

.bat

@echo off
setlocal enabledelayedexpansion
for /l %%i in (1,1,10) do (
    set /a r=%1*%%i
    echo %1 x %%i = !r!
)

bash

#!/bin/bash
for i in $(seq 1 10); do
    echo "$1 x $i = $(( $1 * $i ))"
done

En .bat, dentro de un bloque con paréntesis una variable cambia de valor en cada vuelta, así que se lee con !r! (expansión retardada) y no con %r%.

3.3 Recorrer los argumentos

Muestra cada argumento recibido, uno por línea, sin importar cuántos sean.

.bat

@echo off
for %%a in (%*) do echo Argumento: %%a

bash

#!/bin/bash
for a in "$@"; do
    echo "Argumento: $a"
done

3.4 Adivina el número

El número secreto es 7. Pide números hasta que el usuario acierte.

.bat

@echo off
set secreto=7
:pedir
set /p n=Adivina el numero: 
if "%n%"=="%secreto%" goto fin
echo Incorrecto
goto pedir
:fin
echo Acertaste!

bash

#!/bin/bash
secreto=7
read -p "Adivina el numero: " n
while [ "$n" -ne "$secreto" ]; do
    echo "Incorrecto"
    read -p "Adivina el numero: " n
done
echo "Acertaste!"

3.5 Barrido de red

Haz ping a las IP 192.168.1.1 a 192.168.1.10 y muestra solo las que respondan.

.bat

@echo off
for /l %%i in (1,1,10) do (
    ping -n 1 -w 500 192.168.1.%%i | find "TTL=" >nul && echo 192.168.1.%%i activa
)

bash

#!/bin/bash
for i in {1..10}; do
    ping -c 1 -W 1 192.168.1.$i > /dev/null 2>&1 && echo "192.168.1.$i activa"
done

Reto: haz que el rango de IP (por ejemplo 192.168.1) se pase como argumento.

Nivel 4: ficheros, directorios y texto

Objetivo: crear carpetas, escribir y leer ficheros, hacer copias y buscar texto.

4.1 Estructura de carpetas

Crea la carpeta proyecto con las subcarpetas docs, src y backup.

.bat

@echo off
mkdir proyecto\docs proyecto\src proyecto\backup
echo Estructura creada

bash

#!/bin/bash
mkdir -p proyecto/{docs,src,backup}
echo "Estructura creada"

4.2 Escribir y leer un fichero

Crea informe.txt con el usuario y la fecha (una línea cada uno) y muéstralo por pantalla.

.bat

@echo off
echo Informe de %USERNAME%> informe.txt
echo Fecha: %DATE%>> informe.txt
type informe.txt

bash

#!/bin/bash
echo "Informe de $USER" > informe.txt
echo "Fecha: $(date +%d/%m/%Y)" >> informe.txt
cat informe.txt

> crea o sobrescribe el fichero; >> añade al final.

4.3 Contar ficheros .txt

Recibe una carpeta y di cuántos ficheros .txt contiene (sin entrar en subcarpetas).

.bat

@echo off
set n=0
for %%f in ("%~1\*.txt") do set /a n+=1
echo Hay %n% ficheros .txt

bash

#!/bin/bash
n=$(find "$1" -maxdepth 1 -name "*.txt" | wc -l)
echo "Hay $n ficheros .txt"

4.4 Copia de seguridad con fecha

Copia la carpeta recibida como argumento a una carpeta nueva llamada backup_AAAAMMDD.

.bat

@echo off
set fecha=%DATE:~6,4%%DATE:~3,2%%DATE:~0,2%
xcopy "%~1" "backup_%fecha%\" /E /I /Y
echo Copia creada en backup_%fecha%

bash

#!/bin/bash
fecha=$(date +%Y%m%d)
cp -r "$1" "backup_$fecha"
echo "Copia creada en backup_$fecha"

La versión .bat da por hecho que %DATE% tiene el formato dd/mm/aaaa. Comprueba con echo %DATE% qué formato usa tu Windows y ajusta las posiciones si no coincide.

4.5 Buscar texto en un log

Recibe un fichero y muestra las líneas que contengan error (sin distinguir mayúsculas), seguidas de cuántas son.

.bat

@echo off
findstr /i "error" "%~1"
echo ---
findstr /i "error" "%~1" | find /c /v ""

bash

#!/bin/bash
grep -i "error" "$1"
echo "---"
grep -ic "error" "$1"

Nivel 5: administración del sistema

Objetivo: gestionar procesos, usuarios, recursos y servicios. Haz estos ejercicios en una máquina virtual: algunos necesitan permisos de administrador (.bat: cmd como administrador; bash: sudo).

5.1 Cerrar un proceso con confirmación

Recibe el nombre de un proceso, muéstralo y pregunta si se quiere cerrar. Solo lo cierra si la respuesta es S.

.bat

@echo off
tasklist | find /i "%~1"
set /p ok=Cerrar %~1 (S/N)? 
if /i "%ok%"=="S" taskkill /im "%~1" /f

bash

#!/bin/bash
pgrep -l "$1"
read -p "Cerrar $1 (S/N)? " ok
if [[ "$ok" =~ ^[sS]$ ]]; then
    pkill "$1"
fi

5.2 Crear usuarios desde un fichero

Lee usuarios.txt (un nombre por línea) y crea un usuario por cada línea con una contraseña inicial.

.bat

@echo off
for /f %%u in (usuarios.txt) do (
    net user %%u P@ssw0rd1 /add
    echo Usuario %%u creado
)

bash

#!/bin/bash
if [ "$EUID" -ne 0 ]; then
    echo "Ejecuta como root"
    exit 1
fi
while read -r u; do
    useradd -m "$u" && echo "$u:P@ssw0rd1" | chpasswd && echo "Usuario $u creado"
done < usuarios.txt

La contraseña en claro es solo para práctica. Reto: en Linux, fuerza el cambio en el primer inicio de sesión con chage -d 0 "$u".

5.3 Informe de estado del equipo

Guarda en estado.txt la fecha y el espacio en disco, y muéstralo. En bash añade también la memoria.

.bat

@echo off
echo Informe %DATE% %TIME%> estado.txt
powershell -NoProfile -Command "Get-PSDrive -PSProvider FileSystem | Select-Object Name,Used,Free" >> estado.txt
type estado.txt

bash

#!/bin/bash
{
    echo "Informe $(date)"
    df -h
    free -h
} > estado.txt
cat estado.txt

5.4 Vigilar un servicio

Recibe el nombre de un servicio (en Windows, por ejemplo Spooler; en Linux, por ejemplo ssh). Si está parado, arráncalo.

.bat

@echo off
sc query "%~1" | find "RUNNING" >nul
if %errorlevel%==0 (
    echo %~1 esta activo
) else (
    echo %~1 parado, arrancando...
    net start "%~1"
)

bash

#!/bin/bash
if systemctl is-active --quiet "$1"; then
    echo "$1 esta activo"
else
    echo "$1 parado, arrancando..."
    systemctl start "$1"
fi

Reto: programa este script para que se ejecute cada 5 minutos con schtasks (Windows) o cron (Linux).

Nivel 6: recorrer ficheros paso a paso

En esta serie mejoras un mismo script ejercicio a ejercicio. Cada versión funciona, pero tiene un fallo que corriges en la siguiente. Antes de mirar la solución, prueba tu versión con un fichero que tenga líneas con espacios, una línea vacía y una ruta que no exista.

Fichero de prueba lista.txt:

manzana roja
pera

kiwi verde y dulce

6.1 Mostrar un fichero con número de línea

Muestra lista.txt línea a línea con el formato 1: contenido.

Primera versión en bash:

#!/bin/bash
n=1
for linea in $(cat lista.txt); do
    echo "$n: $linea"
    n=$((n+1))
done

La salida no es la esperada: manzana y roja salen como líneas distintas y la línea vacía desaparece. for separa por espacios y saltos de línea. La forma correcta de leer línea a línea es while read:

bash

#!/bin/bash
n=1
while IFS= read -r linea; do
    echo "$n: $linea"
    n=$((n+1))
done < lista.txt

IFS= evita que se recorten los espacios y -r evita que se interpreten las barras invertidas.

Primera versión en .bat:

@echo off
set n=0
for /f %%l in (lista.txt) do (
    set /a n+=1
    echo %n%: %%l
)

Tiene tres fallos: %n% se calcula una sola vez antes del bucle (siempre muestra 0), for /f solo coge la primera palabra de cada línea y se salta las líneas vacías. Se corrigen con delims= y expansión retardada:

.bat

@echo off
setlocal enabledelayedexpansion
set n=0
for /f "usebackq delims=" %%l in ("lista.txt") do (
    set /a n+=1
    echo !n!: %%l
)

Esta versión sigue saltando la línea vacía. Reto: usa findstr /n "^" para conservarla:

@echo off
for /f "delims=" %%l in ('findstr /n "^" lista.txt') do echo %%l

6.2 La ruta llega por parámetro

El fichero ya no es fijo: llega como primer argumento. Si falta el argumento o no es un fichero, muestra el error por la salida de errores y termina con un código distinto de 0. Crea una función (o subrutina) para los errores.

bash

#!/bin/bash
error() {
    echo "Error: $1" >&2
    exit "$2"
}

[ $# -eq 0 ] && error "falta la ruta del fichero" 1
[ -f "$1" ] || error "$1 no es un fichero" 2
[ -r "$1" ] || error "no se puede leer $1" 3

n=1
while IFS= read -r linea; do
    echo "$n: $linea"
    n=$((n+1))
done < "$1"

.bat

@echo off
setlocal enabledelayedexpansion
if "%~1"=="" (
    echo Error: falta la ruta del fichero 1>&2
    exit /b 1
)
if not exist "%~1" (
    echo Error: %~1 no existe 1>&2
    exit /b 2
)
if exist "%~1\" (
    echo Error: %~1 es una carpeta 1>&2
    exit /b 3
)
set n=0
for /f "usebackq delims=" %%l in ("%~1") do (
    set /a n+=1
    echo !n!: %%l
)

Para ver el código de salida: en bash ./ver.sh; echo $?, en cmd ver.bat & echo %errorlevel%. Prueba sin argumento, con un fichero que no existe y con una carpeta.

6.3 Lista variable de ficheros

El script recibe uno o más ficheros. Para cada uno muestra una cabecera === nombre === y su contenido numerado. Pon el cuerpo en una función (bash) o subrutina (.bat).

La primera idea suele ser reutilizar la comprobación del ejercicio anterior dentro de la función, con exit. Funciona hasta que un fichero no existe:

mostrar() {
    [ -f "$1" ] || { echo "Error: $1 no existe" >&2; exit 1; }
    # ...
}

exit termina todo el script, así que los ficheros que van detrás del que falta no se procesan. Hay que salir solo de la función (return en bash, exit /b en .bat), avisar y seguir. De paso, cuenta los ficheros con problemas y devuélvelo como código de salida.

bash

#!/bin/bash
mostrar() {
    if [ ! -f "$1" ]; then
        echo "Aviso: $1 no existe, se omite" >&2
        return 1
    fi
    echo "=== $1 ==="
    local n=1 linea
    while IFS= read -r linea; do
        echo "$n: $linea"
        n=$((n+1))
    done < "$1"
}

fallos=0
for f in "$@"; do
    mostrar "$f" || fallos=$((fallos+1))
done
echo "Ficheros con problemas: $fallos"
[ "$fallos" -eq 0 ]

.bat

@echo off
setlocal enabledelayedexpansion
set fallos=0
for %%f in (%*) do (
    call :mostrar "%%~f"
    if errorlevel 1 set /a fallos+=1
)
echo Ficheros con problemas: %fallos%
exit /b %fallos%

:mostrar
if not exist "%~1" (
    echo Aviso: %~1 no existe, se omite 1>&2
    exit /b 1
)
echo === %~1 ===
set n=0
for /f "usebackq delims=" %%l in ("%~1") do (
    set /a n+=1
    echo !n!: %%l
)
exit /b 0

En bash, local evita que las variables de la función pisen las del script. En .bat, exit /b dentro de una subrutina vuelve al call; sin /b se cerraría la consola.

6.4 El ámbito de los parámetros

Refactoriza: mete el recorrido de todos los ficheros en una función mostrarTodos y llámala al final del script. Comprueba qué pasa.

Versión que no funciona:

mostrarTodos() {
    for f in "$@"; do
        mostrar "$f"
    done
}

mostrarTodos

call :todos

No muestra nada. Dentro de una función, $@ son los parámetros de la función, no los del script, y aquí se la llama sin ninguno. En .bat pasa lo mismo: dentro de una subrutina, %* son los argumentos del call. Hay que pasárselos explícitamente:

bash

mostrarTodos "$@"

.bat

call :todos %*
exit /b

:todos
for %%f in (%*) do call :mostrar "%%~f"
exit /b

Regla práctica: una función solo ve lo que le pasas. La única excepción en bash es $0, que siempre es el nombre del script.

6.5 Contar coincidencias en varios ficheros

El primer argumento es una palabra y el resto son ficheros. Para cada fichero que exista muestra cuántas líneas contienen la palabra (sin distinguir mayúsculas). Los que no existan se avisan y se omiten. Si faltan argumentos, muestra el modo de uso. Pista: shift descarta el primer parámetro y desplaza los demás.

bash

#!/bin/bash
[ $# -ge 2 ] || { echo "Uso: $0 palabra fichero..." >&2; exit 1; }

palabra=$1
shift

for f in "$@"; do
    if [ -f "$f" ]; then
        echo "$f: $(grep -ic -- "$palabra" "$f")"
    else
        echo "Aviso: $f no existe, se omite" >&2
    fi
done

.bat

@echo off
if "%~2"=="" (
    echo Uso: %0 palabra fichero... 1>&2
    exit /b 1
)
set palabra=%~1
shift

:siguiente
if "%~1"=="" exit /b 0
if exist "%~1" (
    for /f %%c in ('findstr /i /c:"%palabra%" "%~1" ^| find /c /v ""') do echo %~1: %%c
) else (
    echo Aviso: %~1 no existe, se omite 1>&2
)
shift
goto siguiente

Retos: haz que el script acepte también la opción -n para mostrar el número de cada línea que coincide, y que funcione con palabras que contengan espacios.

Lo que ha quedado claro en esta serie

  • En bash, for x in $(cat fichero) separa por espacios y pierde líneas vacías; para leer línea a línea usa while IFS= read -r.
  • En .bat, for /f solo toma la primera palabra de cada línea y se salta las vacías; delims= lo arregla en parte y findstr /n "^" conserva las vacías.
  • Dentro de un bloque con paréntesis en .bat, las variables que cambian se leen con !var! y setlocal enabledelayedexpansion.
  • exit en una función de bash termina el script entero; return solo la función. En .bat usa exit /b en las subrutinas.
  • Una función o subrutina solo ve los parámetros que se le pasan: llama a f "$@" o a call :f %*.

Nivel 7: scripts robustos y tareas programadas

Objetivo: que un script se pueda dejar funcionando solo: que registre lo que hace, acepte opciones, limpie lo antiguo y se ejecute a una hora fija. Haz los ejercicios 7.3 y 7.4 en una carpeta de pruebas: borran copias antiguas.

7.1 Un registro (log) con fecha

Crea una función log que reciba un mensaje y lo escriba en registro.log con la fecha y la hora, además de mostrarlo por pantalla. Pruébala con tres mensajes seguidos.

La primera idea suele ser echo "$(date) $1" > registro.log. Funciona, pero > sobrescribe el fichero en cada llamada y al final solo queda el último mensaje. Hay que añadir con >>.

bash

#!/bin/bash
LOG="registro.log"
log() {
    echo "$(date '+%Y-%m-%d %H:%M:%S') $1" | tee -a "$LOG"
}

log "Inicio del script"
log "Procesando $1"
log "Fin del script"

.bat

@echo off
set LOG=registro.log
call :log "Inicio del script"
call :log "Procesando %~1"
call :log "Fin del script"
exit /b

:log
echo %DATE% %TIME% %~1
>> "%LOG%" echo %DATE% %TIME% %~1
exit /b

tee -a escribe en pantalla y añade al fichero a la vez. En .bat la redirección va al principio de la línea: si el mensaje terminara en un 1 o un 2 (por ejemplo "Procesando 2"), 2>> se leería como una redirección de errores y el texto saldría mal.

7.2 Opciones en la línea de comandos

Haz un script contar con la forma contar [-v] [-e extension] carpeta: cuenta los ficheros de la carpeta con esa extensión (por defecto txt); con -v muestra además sus nombres. Si falta la carpeta o no existe, da el error y un código de salida distinto de 0.

En bash se usa getopts. Después de procesar las opciones hay que hacer shift $((OPTIND - 1)); si no, $1 sigue siendo la primera opción y no la carpeta.

bash

#!/bin/bash
uso="Uso: $0 [-v] [-e extension] carpeta"
ext="txt"
verbose=0

while getopts "ve:" opcion; do
    case $opcion in
        v) verbose=1 ;;
        e) ext=$OPTARG ;;
        *) echo "$uso" >&2; exit 1 ;;
    esac
done
shift $((OPTIND - 1))

[ $# -eq 1 ] || { echo "$uso" >&2; exit 1; }
[ -d "$1" ] || { echo "Error: $1 no es una carpeta" >&2; exit 2; }

n=0
for f in "$1"/*."$ext"; do
    [ -e "$f" ] || continue
    n=$((n+1))
    [ "$verbose" -eq 1 ] && echo "$f"
done
echo "Hay $n ficheros .$ext"

.bat

En .bat no hay getopts: se recorren los argumentos con shift. Ojo: -e consume dos argumentos (la opción y su valor), así que lleva dos shift.

@echo off
setlocal
set ext=txt
set verbose=0

:opciones
if "%~1"=="-v" (
    set verbose=1
    shift
    goto opciones
)
if "%~1"=="-e" (
    set ext=%~2
    shift
    shift
    goto opciones
)
if "%~1"=="" (
    echo Uso: %0 [-v] [-e extension] carpeta 1>&2
    exit /b 1
)
if not exist "%~1\" (
    echo Error: %~1 no es una carpeta 1>&2
    exit /b 2
)

set n=0
for %%f in ("%~1\*.%ext%") do (
    set /a n+=1
    if "%verbose%"=="1" echo %%f
)
echo Hay %n% ficheros .%ext%

Prueba: contar carpeta, contar -v carpeta, contar -e log -v carpeta, contar (sin carpeta) y contar -e (sin valor).

7.3 Copia de seguridad con rotación

Copia la carpeta recibida a copias/backup_AAAAMMDD_HHMMSS y conserva solo las N copias más recientes (por defecto 3), borrando las anteriores. El nombre lleva la fecha y la hora en orden de mayor a menor, así que ordenar por nombre es ordenar por antigüedad.

bash

#!/bin/bash
origen=$1
mantener=${2:-3}
destino="./copias"

[ -d "$origen" ] || { echo "Uso: $0 carpeta [copias_a_mantener]" >&2; exit 1; }
mkdir -p "$destino"

copia="$destino/backup_$(date +%Y%m%d_%H%M%S)"
cp -r "$origen" "$copia" && echo "Copia creada: $copia"

ls -1d "$destino"/backup_* | sort | head -n -"$mantener" | while read -r vieja; do
    rm -rf -- "$vieja"
    echo "Eliminada: $vieja"
done

head -n -N (todas las líneas menos las últimas N) es de GNU/Linux. Con menos de N copias no devuelve nada y no se borra nada.

.bat

@echo off
setlocal
set origen=%~1
set mantener=%~2
if "%mantener%"=="" set mantener=3

if not exist "%origen%\" (
    echo Uso: %0 carpeta [copias_a_mantener] 1>&2
    exit /b 1
)
if not exist copias mkdir copias

set hora=%TIME:~0,2%
if "%hora:~0,1%"==" " set hora=0%hora:~1,1%
set marca=%DATE:~6,4%%DATE:~3,2%%DATE:~0,2%_%hora%%TIME:~3,2%%TIME:~6,2%

xcopy "%origen%" "copias\backup_%marca%\" /E /I /Y >nul && echo Copia creada: copias\backup_%marca%

for /f "skip=%mantener% delims=" %%d in ('dir /b /ad /o-n "copias\backup_*"') do (
    rd /s /q "copias\%%d"
    echo Eliminada: copias\%%d
)

Tres detalles: a las horas de un solo dígito %TIME% pone un espacio delante (" 9"), y por eso se rellena con un cero; dir /o-n ordena por nombre de mayor a menor, así que skip=N salta las N copias más recientes y borra el resto; y la fecha da por hecho el formato dd/mm/aaaa, como en el 4.4.

7.4 Programar la copia a una hora fija

Programar el script del 7.3 para que se ejecute cada día a las 02:00 con 5 copias como máximo. Para probarlo sin esperar, programa primero una ejecución cada minuto y cámbiala después.

bash (cron)

crontab -e

Y en el editor, una línea con el formato minuto hora día-del-mes mes día-de-la-semana comando:

# Prueba: cada minuto
* * * * * /home/usuario/copia.sh /home/usuario/datos 5 >> /home/usuario/copia.log 2>&1

# Definitiva: cada día a las 02:00
0 2 * * * /home/usuario/copia.sh /home/usuario/datos 5 >> /home/usuario/copia.log 2>&1

.bat (schtasks)

rem Prueba: cada minuto
schtasks /create /tn "CopiaDiaria" /tr "C:\scripts\copia.bat C:\datos 5" /sc minute /mo 1

rem Definitiva: cada día a las 02:00 (sustituye la anterior)
schtasks /create /tn "CopiaDiaria" /tr "C:\scripts\copia.bat C:\datos 5" /sc daily /st 02:00 /f

rem Ver y borrar la tarea
schtasks /query /tn "CopiaDiaria"
schtasks /delete /tn "CopiaDiaria" /f

El fallo típico. El script funciona a mano y, al programarlo, las copias aparecen en otro sitio o no aparecen. Una tarea programada no arranca en la carpeta del script: cron arranca en la carpeta personal del usuario y schtasks en C:\Windows\System32. La ruta relativa ./copias apunta entonces a un lugar inesperado. Se corrige haciendo que el script se coloque en su propia carpeta al empezar:

bash

cd "$(dirname "$0")" || exit 1

.bat

cd /d "%~dp0"

Pon esa línea justo después de @echo off (o de #!/bin/bash) en el script del 7.3. Redirigir la salida a un fichero, como hace la línea de cron, es lo que permite saber qué pasó cuando nadie está mirando. Cuando termines las pruebas, borra la tarea de prueba para que no siga copiando cada minuto.

7.5 Vigilar el espacio en disco

Recibe una ruta o unidad y un umbral de uso en porcentaje (por defecto 80). Si el uso lo alcanza o lo supera, anota un aviso con fecha en disco.log, lo muestra y termina con código 1. Si no, muestra que todo va bien y termina con 0. Así se puede programar con el 7.4 y consultar el código de salida o el log.

bash

#!/bin/bash
ruta=${1:-/}
umbral=${2:-80}
uso=$(df --output=pcent "$ruta" | tail -1 | tr -dc '0-9')

if [ "$uso" -ge "$umbral" ]; then
    echo "$(date '+%F %T') AVISO: $ruta al ${uso}% - umbral ${umbral}%" | tee -a disco.log
    exit 1
fi
echo "$ruta al ${uso}%: correcto"

.bat

@echo off
setlocal
set unidad=%~1
if "%unidad%"=="" set unidad=C
set umbral=%~2
if "%umbral%"=="" set umbral=80

for /f %%p in ('powershell -NoProfile -Command "$d=Get-PSDrive %unidad%; [int](100*$d.Used/($d.Used+$d.Free))"') do set uso=%%p

if %uso% GEQ %umbral% (
    >> disco.log echo %DATE% %TIME% AVISO: %unidad%: al %uso%%% - umbral %umbral%%%
    echo AVISO: %unidad%: al %uso%%%
    exit /b 1
)
echo %unidad%: al %uso%%%: correcto

En .bat, un porcentaje literal se escribe %%. Y no pongas paréntesis dentro del texto de un echo que está en un bloque ( ... ): el primer ) cerraría el bloque antes de tiempo. Para probar el aviso, pasa un umbral bajo, por ejemplo 1.

Reto: haz que el script use la función log del 7.1 y que acepte la opción -u umbral con el método del 7.2.

Lo que ha quedado claro en este nivel

  • Un registro se escribe con >> (añadir), no con > (sobrescribir). Con tee -a se muestra y se guarda a la vez.
  • En bash, tras getopts hay que hacer shift $((OPTIND - 1)). En .bat, cada opción se consume con shift y las que llevan valor necesitan dos.
  • Si el nombre incluye la fecha de mayor a menor unidad (año, mes, día, hora), ordenar por nombre es ordenar por antigüedad, y eso permite borrar las copias viejas.
  • Una tarea programada no empieza en la carpeta del script: usa cd "$(dirname "$0")" o cd /d "%~dp0", o rutas absolutas.
  • Un script desatendido debe dejar rastro: log, código de salida y salida redirigida a un fichero.

Proyecto final: menú de administración

Un único script con un menú que se repite hasta elegir Salir. Opciones: información del sistema, espacio en disco, comprobar conectividad con un host y salir. Reutiliza lo de los niveles 1 a 5.

.bat

@echo off
:menu
cls
echo ===== MENU ADMIN =====
echo 1) Informacion del sistema
echo 2) Espacio en disco
echo 3) Comprobar conectividad
echo 4) Salir
set /p op=Elige una opcion: 
if "%op%"=="1" goto info
if "%op%"=="2" goto disco
if "%op%"=="3" goto red
if "%op%"=="4" exit /b 0
echo Opcion no valida
pause
goto menu

:info
echo Usuario: %USERNAME% - Equipo: %COMPUTERNAME%
pause
goto menu

:disco
powershell -NoProfile -Command "Get-PSDrive -PSProvider FileSystem | Select-Object Name,Used,Free"
pause
goto menu

:red
set /p host=Host a comprobar: 
ping -n 1 %host% | find "TTL=" >nul
if %errorlevel%==0 (echo %host% responde) else (echo %host% NO responde)
pause
goto menu

bash

#!/bin/bash
info()  { echo "Usuario: $USER - Equipo: $(hostname)"; }
disco() { df -h; }
red() {
    read -p "Host a comprobar: " host
    if ping -c 1 "$host" > /dev/null 2>&1; then
        echo "$host responde"
    else
        echo "$host NO responde"
    fi
}

while true; do
    echo "===== MENU ADMIN ====="
    echo "1) Informacion del sistema"
    echo "2) Espacio en disco"
    echo "3) Comprobar conectividad"
    echo "4) Salir"
    read -p "Elige una opcion: " op
    case $op in
        1) info ;;
        2) disco ;;
        3) red ;;
        4) exit 0 ;;
        *) echo "Opcion no valida" ;;
    esac
    echo
done
