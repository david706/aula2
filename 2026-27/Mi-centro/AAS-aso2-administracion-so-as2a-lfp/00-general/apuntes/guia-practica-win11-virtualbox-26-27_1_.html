Instalación de Windows 11 en VirtualBox

Despliegue virtualizado de Windows 11, configuración de la máquina virtual, gestión de la fase OOBE con cuenta local y comprobación del tipo de licencia instalada.

Módulo
Implantación de Sistemas Operativos

1.º ASIR — 26/27
Unidad
UD1

Objetivo de la práctica

Realizar el despliegue virtualizado de Windows 11 en VirtualBox, sortear la exigencia de registro de cuenta de Microsoft en la fase OOBE (Out-Of-Box Experience) ejecutando comandos de consola, y configurar un usuario local con privilegios administrativos.

01

Requisitos y configuración de la máquina virtual

Para garantizar un funcionamiento fluido de Windows 11 en entorno virtualizado, la máquina virtual en VirtualBox debe cumplir con la siguiente especificación de hardware.

02

Proceso de instalación básica de Windows 11

  1. Descargar la imagen ISO oficial de Windows 11 desde la web de Microsoft o el repositorio de recursos del módulo.
  2. Iniciar la MV e insertar la ISO en la unidad óptica virtual.
  3. Seleccionar idioma (Español), formato de hora y distribución de teclado.
  4. Pulsar en «Instalar ahora» y seleccionar «No tengo clave de producto» para continuar con la edición Windows 11 Pro.
  5. Elegir «Instalación personalizada: instalar solo Windows (avanzado)», seleccionar el espacio sin asignar del disco de 64 GB y proceder.
03

Procedimiento para omitir la cuenta de Microsoft (bypass OOBE)

Tras el primer reinicio, Windows 11 inicia el asistente OOBE. Al llegar a la pantalla «Conectémonos a una red» o «Inicia sesión con tu cuenta de Microsoft», el sistema bloquea el avance si no hay conexión o no se inicia sesión. A continuación, los 3 métodos para omitir este requisito.

Método 1 · Comando OOBE\BYPASSNRO

Recomendado

Este método modifica temporalmente el flujo de instalación para añadir la opción de configuración local sin conexión.

  1. En la pantalla de red u OOBE, pulsa Shift + F10 (o Fn + Shift + F10) para abrir la consola de comandos (CMD).
  2. Ejecuta el siguiente comando y pulsa Enter:
C:\> OOBE\BYPASSNRO
  1. La máquina virtual se reiniciará automáticamente. Al regresar a la pantalla de red, aparecerá la opción adicional «No tengo Internet».
  2. Haz clic en «No tengo Internet» y luego en «Continuar con la configuración limitada». Introduce el nombre del usuario local (ej. AlumnoISO) y la contraseña.

Método 2 · Comando directo (ms-cxh)

Alternativo

En versiones recientes de Windows 11, puedes forzar la interfaz de usuario local directamente.

  1. Abre la consola CMD con Shift + F10.
  2. Ejecuta el comando:
C:\> start ms-cxh:localonly

Se abrirá de inmediato el cuadro de diálogo nativo para ingresar el nombre de la cuenta de usuario local.

Método 3 · Creación manual del usuario vía consola

Si los anteriores fallan

Si los métodos anteriores están bloqueados, se puede crear la cuenta de usuario manualmente antes de finalizar el OOBE.

C:\> net user "AlumnoISO" "Password123" /add C:\> net localgroup Administradores "AlumnoISO" /add C:\> cd oobe C:\> msoobe.exe && shutdown -r -t 0
04

Comprobaciones post-instalación y verificación de licencia

Una vez completada la instalación y dentro del escritorio de Windows 11, el alumnado deberá realizar las siguientes comprobaciones.

  • Comprobación de usuario local: abrir símbolo del sistema (CMD) y ejecutar whoami y net user AlumnoISO para verificar la pertenencia al grupo de Administradores.
  • Inspección del estado de licencia: ejecutar slmgr.vbs /dli para abrir el cuadro de diálogo de información de la licencia.
  • Identificación del tipo de licencia: anotar en la memoria del laboratorio si la instalación se encuentra en período de gracia de activación, y resumir las diferencias entre licencias OEM, Retail y Volumen (KMS/MAK).
