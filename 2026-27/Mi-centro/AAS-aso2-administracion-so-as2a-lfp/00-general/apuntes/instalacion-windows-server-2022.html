Guía práctica: instalar Windows Server 2022

Paso a paso para montar SRV-ASO (Windows Server 2022 con escritorio, IP 192.168.70.10) en una máquina virtual y dejarlo listo para los apartados de acceso remoto.

Cómo usar esta guía

Cada apartado se despliega pulsando su título. Los recuadros siguen el mismo código que el tema:

Descargar la ISO

  1. Entra en el Microsoft Evaluation Center y busca Windows Server 2022.
  2. Rellena el formulario y descarga la ISO en español (unos 5 GB).
  3. Guárdala en una carpeta que encuentres luego desde el programa de virtualización.
🧠 Versión de evaluación

La ISO de evaluación funciona 180 días con todas las funciones. Para un curso es suficiente. Puedes ver los días que te quedan con slmgr /dlv.

⚠️ Usa la ISO de evaluación: no necesitas ninguna clave

La versión de evaluación es una ISO distinta a la normal y ya viene preparada para funcionar sin clave de producto. No existe una «clave de evaluación» que puedas escribir en una ISO normal para convertirla en evaluación.

Cómo reconocerla: el nombre del archivo lleva la palabra EVAL, algo como SERVER_EVAL_x64FRE_es-es.iso. Si tu ISO no la lleva (por ejemplo, te la ha pasado alguien o viene de otra web), descarga la buena del Evaluation Center.

3 · El asistente de instalación
  1. Arranca la VM. Si aparece «Press any key to boot from CD or DVD…», pulsa una tecla enseguida: tienes unos segundos.
  2. Idioma y teclado. Idioma: Español (España). Formato de hora: Español (España). Teclado: Español. Pulsa Siguiente y después Instalar ahora.
  3. Edición. Con la ISO de evaluación, después de Instalar ahora no se pide ninguna clave: aparece directamente la lista de ediciones. Este es el paso donde más gente se equivoca (mira el recuadro de abajo).
  4. Licencia. Marca «Acepto los términos de licencia» y pulsa Siguiente.
  5. Tipo de instalación. Elige «Personalizada: instalar solo Windows (avanzado)». La opción de actualizar solo sirve si ya hay un Windows Server en el disco.
  6. Disco. Selecciona «Espacio sin asignar en la unidad 0» y pulsa Siguiente. El instalador crea solo las particiones que necesita.
  7. Copia de archivos. Tarda entre 5 y 15 minutos. La VM se reiniciará sola un par de veces. No pulses ninguna tecla si vuelve a salir el mensaje de arrancar desde DVD.

⚠️ Elige la que dice «Experiencia de escritorio»

La opción que viene marcada por defecto es la instalación Server Core: sin escritorio, solo una consola de comandos. Si la instalas por error, no se puede convertir después en una versión con escritorio: toca reinstalar.

Para este curso necesitamos escritorio, porque SRV-ASO va a ser servidor de Escritorio remoto.

⚠️ ¿Te aparece la pantalla «Activar Windows» pidiendo una clave de producto?

Entonces no estás usando la ISO de evaluación. No busques claves por Internet ni pulses «No tengo clave de producto»: lo correcto es cambiar de ISO.

  1. Apaga la VM.
  2. Descarga la ISO de evaluación del Microsoft Evaluation Center (apartado 1).
  3. Cámbiala en la unidad de CD/DVD de la VM y vuelve a arrancar.

Sabrás que es la buena porque en la lista de ediciones todas llevan la palabra Evaluation.

🧠 Standard o Datacenter

Las dos ediciones son técnicamente casi iguales. La diferencia está sobre todo en la licencia: Datacenter permite máquinas virtuales ilimitadas sobre ese servidor y añade funciones avanzadas de almacenamiento y red. Para el laboratorio, Standard es suficiente.

⚠️ «Windows no encuentra ningún disco»

Pasa sobre todo en VMware o VirtualBox con un controlador de disco poco habitual. Apaga la VM, cambia el controlador del disco a SATA (o NVMe en VMware) y vuelve a empezar.

4 · Primer arranque: la contraseña del Administrador

Al terminar, el sistema pide la contraseña de la cuenta local Administrador.

🧠 Requisitos de complejidad

Por defecto, Windows Server exige al menos 8 caracteres y que use tres de estos cuatro tipos: mayúsculas, minúsculas, números y símbolos. Además, no puede contener el nombre de la cuenta.

Ejemplo válido: Aso.2026srv. Ejemplo no válido: administrador1.

⚠️ Apúntala

Es la cuenta con la que entrarás por RDP, WinRM y SSH en el resto del tema. Si la olvidas, la forma más rápida de recuperarte es volver a una instantánea… y todavía no tienes ninguna.

Iniciar sesión: el Ctrl+Alt+Supr en una VM

La pantalla de bloqueo pide Ctrl+Alt+Supr, pero si lo pulsas de verdad lo captura tu propio equipo. Usa la combinación del programa:

ProgramaCombinación
VirtualBoxTecla Host (normalmente Ctrl derecho) + Supr, o menú Entrada → Teclado → Insertar Ctrl-Alt-Supr
VMwareCtrl+Alt+Insert
Hyper-VCtrl+Alt+Fin, o el botón de la barra de la ventana

Al entrar se abre solo el Administrador del servidor. Si aparece un aviso para probar Windows Admin Center, puedes cerrarlo.

5 · Configuración posterior a la instalación

Todo se hace en PowerShell como administrador (clic derecho en Inicio → Terminal (Administrador) o Windows PowerShell (Administrador)). También puedes hacerlo con el menú de texto sconfig o desde el Administrador del servidor → Servidor local.

5.1 · Herramientas de invitado

Mejoran el ratón, la resolución de pantalla y el portapapeles compartido.

  • VirtualBox: menú Dispositivos → Insertar imagen de CD de las «Guest Additions» y ejecuta VBoxWindowsAdditions.exe.
  • VMware: menú VM → Install VMware Tools.
  • Hyper-V: ya vienen integradas.

Reinicia cuando termine.

5.2 · Cambiar el nombre del equipo

El instalador pone un nombre aleatorio tipo WIN-8K2J3L4M5N6. Lo cambiamos a SRV-ASO:

Rename-Computer -NewName "SRV-ASO" -Restart

5.3 · Poner la IP fija

Primero mira cómo se llama tu adaptador de red:

Get-NetAdapter

Normalmente es Ethernet. Después asigna la IP (cambia la puerta de enlace y el DNS por los de tu red si son distintos):

New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.70.10 -PrefixLength 24 -DefaultGateway 192.168.70.1
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses 8.8.8.8,1.1.1.1
⚠️ «The object already exists» / «El objeto ya existe»

Sale si el adaptador ya tenía una IP o una puerta de enlace asignada. Quita la configuración anterior y vuelve a lanzar New-NetIPAddress:

Remove-NetIPAddress -InterfaceAlias "Ethernet" -Confirm:$false
Remove-NetRoute -InterfaceAlias "Ethernet" -DestinationPrefix 0.0.0.0/0 -Confirm:$false
🧠 ¿Y si estoy en una red interna sin router?

Si las tres máquinas están en una red interna aislada, no hay puerta de enlace: omite -DefaultGateway. Eso sí, entonces no tendrás Internet, y lo necesitas para Windows Update y para instalar OpenSSH más adelante. Una solución habitual es añadir a la VM un segundo adaptador en NAT.

5.4 · Zona horaria

Set-TimeZone -Id "Romance Standard Time"   # Madrid (UTC+1 / UTC+2 en verano)
Get-Date

5.5 · Permitir el ping

Igual que en el tema: el cortafuegos de Windows bloquea el ping entrante por defecto.

New-NetFirewallRule -DisplayName "Permitir ping" -Protocol ICMPv4 -IcmpType 8 -Action Allow

5.6 · Actualizaciones

Configuración → Windows Update → Buscar actualizaciones. Instálalas y reinicia. Puede tardar un buen rato la primera vez: aprovecha para seguir con otra máquina.

6 · Comprobaciones finales e instantánea
✅ Así debe quedar SRV-ASO
PS C:\> hostname
SRV-ASO

PS C:\> Get-ComputerInfo | Select-Object WindowsProductName, OsVersion

WindowsProductName                          OsVersion
------------------                          ---------
Windows Server 2022 Standard Evaluation     10.0.20348

PS C:\> Get-NetIPAddress -InterfaceAlias "Ethernet" -AddressFamily IPv4 | Select-Object IPAddress, PrefixLength

IPAddress     PrefixLength
---------     ------------
192.168.70.10           24

Y desde UBU-ASO o CLI-ASO, el ping debe responder:

alumno@UBU-ASO:~$ ping -c 2 192.168.70.10
64 bytes from 192.168.70.10: icmp_seq=1 ttl=128 time=0.41 ms
64 bytes from 192.168.70.10: icmp_seq=2 ttl=128 time=0.38 ms

Fíjate en el ttl=128: es el valor inicial típico de Windows (Linux usa 64). Es una pista rápida para saber qué sistema te responde.

✅ Comprobar que es la versión de evaluación

Ejecuta slmgr /dlv. En la ventana que se abre, la descripción debe incluir EVAL y debe aparecer un tiempo restante de unos 180 días. Si es así, está todo correcto.

Haz la instantánea

Apaga la VM (Stop-Computer) y crea una instantánea llamada, por ejemplo, «SRV-ASO recién instalado». Será tu punto de partida seguro para los apartados de RDP, WinRM y SSH.
