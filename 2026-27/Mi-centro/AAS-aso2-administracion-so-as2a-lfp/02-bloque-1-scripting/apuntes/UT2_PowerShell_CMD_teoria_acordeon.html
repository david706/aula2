UT2 · Scripting en Windows: CMD y PowerShell

Módulo: 0374 Administración de Sistemas Operativos · 2º ASIR Resultado de aprendizaje: RA7 — Utiliza lenguajes de guiones en sistemas operativos, describiendo su aplicación y administrando servicios del sistema operativo (20 %)

Propuesta didáctica

En la UT1 aprendiste a programar guiones en Bash. En esta unidad trasladamos esa lógica a Windows con dos intérpretes: CMD, el intérprete clásico, que sigue presente en miles de scripts de inicio de sesión y de mantenimiento, y PowerShell, el lenguaje de administración actual de Windows, que además funciona en Linux y macOS (PowerShell 7).

La idea clave de la unidad: Bash y CMD trabajan con texto; PowerShell trabaja con objetos.

Bloque 1 · CMD: ficheros por lotes

▸ 1.1 Estructura de un fichero .bat
@echo off
rem Esto es un comentario
:: Esto también (más habitual)
setlocal
echo Hola, %USERNAME%. Hoy es %DATE%.
endlocal
Elemento Función
@echo off No muestra cada orden antes de ejecutarla
rem / :: Comentarios
setlocal / endlocal Las variables creadas no "escapan" del script
exit /b n Termina el script (o la subrutina) devolviendo el código n
▸ 1.2 Variables
set nombre=Ana
echo %nombre%

set /a total=5*3+2
set /a contador+=1

set /p edad=Introduce tu edad:
  • Sin espacios alrededor del =: set a = 1 crea la variable "a " con valor " 1".
  • set /a hace aritmética entera. set /p lee del teclado.
  • Variables de entorno útiles: %USERNAME%, %COMPUTERNAME%, %USERPROFILE%, %DATE%, %TIME%, %ERRORLEVEL%, %LOGONSERVER%.
  • Subcadenas: %DATE:~6,4% extrae 4 caracteres desde la posición 6. El formato de la fecha depende del idioma del sistema.
▸ 1.3 Parámetros
Parámetro Significado Equivalente Bash
%0 Nombre del script $0
%1 … %9 Argumentos $1 … $9
%* Todos los argumentos $*
%~1 Argumento 1 sin comillas —
%~nx0 Nombre y extensión del script basename $0
shift Desplaza los argumentos shift
▸ 1.4 Condicionales
if "%~1"=="" (
    echo Uso: %~nx0 nombre
    exit /b 1
)

if /i "%respuesta%"=="s" echo Has dicho que sí

if exist "C:\Datos\" (echo La carpeta existe) else (echo No existe)

if %edad% GEQ 18 echo Mayor de edad

if errorlevel 1 echo La última orden falló

Operadores numéricos: EQU, NEQ, LSS, LEQ, GTR, GEQ. /i ignora mayúsculas.

⚠️ if errorlevel 1 significa "errorlevel mayor o igual que 1", no "igual a 1".

▸ 1.5 Bucles con `for`
:: Recorrer ficheros (en un script, la variable lleva %%)
for %%f in (*.txt) do echo Encontrado: %%f

:: Contador: inicio, incremento, fin
for /l %%i in (1,1,10) do echo Línea %%i

:: Leer un fichero por campos
for /f "tokens=1,2 delims=;" %%a in (usuarios.csv) do echo Usuario %%a, grupo %%b

:: Recorrer la salida de un comando
for /f "skip=1" %%u in ('wmic useraccount get name') do echo %%u
▸ 1.6 Expansión retardada

CMD sustituye %variable% una sola vez, al leer el bloque entero. Dentro de un for o un if (...) el valor no cambia:

@echo off
setlocal enabledelayedexpansion
set /a total=0
for %%f in (*.txt) do (
    set /a total+=1
    echo !total!: %%f
)
echo Total: %total%

Con enabledelayedexpansion, !total! se evalúa en cada vuelta.

▸ 1.7 Saltos y subrutinas
@echo off
call :saludar Ana
call :saludar Luis
exit /b 0

:saludar
echo Hola, %~1
exit /b 0

goto etiqueta salta sin volver; call :etiqueta ejecuta y vuelve (como una función).

▸ 1.8 Comandos de administración habituales
Tarea Comando

Ejemplo completo: copia de seguridad con fecha

@echo off
setlocal
:: copia.bat - Copia una carpeta a C:\Backups con la fecha en el nombre
:: Uso: copia.bat carpeta_origen

if "%~1"=="" (
    echo Uso: %~nx0 carpeta_origen
    exit /b 1
)
if not exist "%~1\" (
    echo ERROR: la carpeta "%~1" no existe
    exit /b 2
)

:: Fecha en formato AAAAMMDD (sistema en español: dd/mm/aaaa)
set "fecha=%DATE:~6,4%%DATE:~3,2%%DATE:~0,2%"
set "destino=C:\Backups\%~n1_%fecha%"

robocopy "%~1" "%destino%" /E /NFL /NDL /NJH /NJS
if %ERRORLEVEL% GEQ 8 (
    echo ERROR en la copia
    exit /b 3
)
echo Copia creada en %destino%
endlocal
exit /b 0

Bloque 2 · PowerShell: fundamentos

▸ 2.1 Qué es PowerShell
  • Windows PowerShell 5.1 viene instalado en Windows (powershell.exe).
  • PowerShell 7 es multiplataforma y de código abierto (pwsh). Funciona en Windows, Linux y macOS.
  • Editor recomendado: Visual Studio Code con la extensión PowerShell (resaltado, depurador, ayuda).
  • Scripts: extensión .ps1. Módulos: .psm1.
▸ 2.2 Cmdlets: verbo-sustantivo

Todos los comandos siguen el patrón Verbo-Sustantivo: Get-Process, Stop-Service, New-Item, Remove-LocalUser.

Get-Verb                              # verbos aprobados
Get-Command -Noun *Service*           # comandos que trabajan con servicios
Get-Command -Verb Get -Module NetTCPIP
Get-Help Get-Service -Examples        # ejemplos de uso
Get-Help Get-Service -Online          # documentación web
Update-Help                           # descarga la ayuda (como administrador)
Get-Alias ls, dir, cd, cat            # alias heredados de CMD y Bash

Con estos cuatro comandos (Get-Command, Get-Help, Get-Member, Get-Alias) puedes descubrir todo lo demás sin memorizar.

▸ 2.3 El pipeline de objetos

En Bash, por la tubería viaja texto, y hay que recortarlo con grep, cut o awk. En PowerShell viajan objetos con propiedades y métodos.

# Bash:        ps aux --sort=-%cpu | head -5
# PowerShell:
Get-Process | Sort-Object CPU -Descending | Select-Object -First 5 Name, Id, CPU

Get-Service | Get-Member                       # ¿qué propiedades y métodos tiene?
Get-Service | Where-Object Status -eq 'Running'
Get-Service | Where-Object { $_.Status -eq 'Stopped' -and $_.StartType -eq 'Automatic' }
Get-ChildItem C:\Windows -File | Measure-Object Length -Sum -Average
Get-Process | Export-Csv procesos.csv -NoTypeInformation
Import-Csv usuarios.csv | Format-Table

$_ (o $PSItem) es el objeto que está pasando por la tubería en ese momento.

Cmdlet Función Parecido en Bash
Where-Object Filtrar grep
Select-Object Elegir propiedades o primeros N cut, head
Sort-Object Ordenar sort
Measure-Object Contar, sumar, media wc, awk
ForEach-Object Hacer algo con cada objeto xargs, while read
Format-Table / Format-List Presentar en pantalla column

⚠️ Los Format-* van siempre al final: convierten los objetos en texto de presentación.

▸ 2.4 Variables y tipos
$nombre = "Ana"
$edad = 20
[int]$numero = Read-Host "Introduce un número"   # fuerza el tipo
$pi = [math]::PI
$hoy = Get-Date
$hoy.DayOfWeek
$nombre.GetType()      # ¿de qué tipo es?
$nombre.ToUpper()
$nombre.Length

Tipos habituales: [int], [double], [string], [bool], [datetime], [array], [hashtable].

⚠️ Read-Host siempre devuelve texto. Sin conversión, "3" + "4" da "34".

Comillas:

$usuario = "Ana"
"Hola, $usuario"                 # Hola, Ana  (dobles: interpolan)
'Hola, $usuario'                 # Hola, $usuario  (simples: literal)
"Tienes $($edad + 1) años"       # $( ) evalúa una expresión dentro de la cadena

Variables automáticas útiles: $args (argumentos), $? (¿funcionó el último comando?), $LASTEXITCODE (código de salida de un programa externo), $PSVersionTable, $IsWindows, $IsLinux (PowerShell 7), $env:USERNAME, $env:PATH.

▸ 2.5 Operadores
Tipo Operadores
Aritméticos + - * / %
Asignación = += -= *= /= ++ --
Comparación -eq -ne -gt -ge -lt -le
Texto -like (comodines *, ?), -match (expresiones regulares), -replace
Colecciones -contains, -in
Lógicos -and -or -not !

Las comparaciones no distinguen mayúsculas por defecto; para distinguirlas se usa el prefijo c: -ceq, -clike.

⚠️ > no compara, redirige a un fichero. if ($a > 5) crea un fichero llamado 5.

▸ 2.6 Entrada y salida

Write-Host "Texto en pantalla" -ForegroundColor Green   # solo pantalla

▸ 2.7 Ejecutar scripts: la política de ejecución
Get-ExecutionPolicy -List
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
.\mi_script.ps1               # siempre con ruta: .\ en la carpeta actual
Unblock-File .\descargado.ps1
Política Qué permite
Restricted Ningún script (defecto en clientes Windows)
RemoteSigned Scripts locales sí; descargados solo si están firmados
AllSigned Solo scripts firmados
Unrestricted / Bypass Todo (no recomendado)

La política no es una barrera de seguridad sino una protección contra ejecuciones accidentales.

▸ 3.4 Parámetros del script

    [Parameter(Mandatory)]

▸ 3.5 Funciones
function Get-Saludo {
    param(
        [Parameter(Mandatory)][string]$Nombre,
        [ValidateRange(0,23)][int]$Hora = (Get-Date).Hour
    )
    if ($Hora -lt 14) { "Buenos días, $Nombre" }
    else              { "Buenas tardes, $Nombre" }
}

Get-Saludo -Nombre Ana
Get-Saludo Luis -Hora 20
  • Todo lo que se "suelta" en la función se devuelve (no solo lo que va tras return).
  • Usa nombres Verbo-Sustantivo con verbos de Get-Verb.
  • Las variables de la función son locales; $script:contador accede a la del script.
▸ 3.6 Ayuda basada en comentarios (documentación)
function Get-Saludo {
<#
.SYNOPSIS
    Devuelve un saludo según la hora.
.DESCRIPTION
    Saluda con "Buenos días" antes de las 14:00 y "Buenas tardes" después.
.PARAMETER Nombre
    Persona a la que se saluda.
.EXAMPLE
    Get-Saludo -Nombre Ana
#>
    param([Parameter(Mandatory)][string]$Nombre)
    ...
}

Con esto, Get-Help Get-Saludo -Full muestra tu documentación como la de cualquier cmdlet. Es obligatorio en todos los scripts entregados (CE9).

▸ 3.7 Módulos: tu propia librería de funciones
# Utilidades.psm1
function Test-EsPar { param([int]$N) $N % 2 -eq 0 }
function Get-LetraDNI { param([int]$Numero) 'TRWAGMYFPDXBNJZSQVHLCKE'[$Numero % 23] }
Export-ModuleMember -Function Test-EsPar, Get-LetraDNI

# programa.ps1
Import-Module "$PSScriptRoot\Utilidades.psm1"
Get-LetraDNI 12345678
Get-Command -Module Utilidades

Módulos del sistema que usarás en el curso: Microsoft.PowerShell.LocalAccounts, NetTCPIP, ScheduledTasks, ActiveDirectory (UT4). Busca más con Find-Module en la PowerShell Gallery.

▸ 4.1 Depurar scripts (CE2)
Herramienta Uso
Set-StrictMode -Version Latest Error si usas variables sin inicializar o propiedades inexistentes
Set-PSDebug -Trace 1 Muestra cada línea al ejecutarse (como bash -x)
Write-Verbose + [CmdletBinding()] Mensajes que solo aparecen con -Verbose

VS Code (F9 y F5) Puntos de interrupción, ver variables, paso a paso

En CMD: quitar @echo off para ver cada orden, y echo / pause en puntos clave.

▸ 4.2 Control de errores
try {
    Get-Content C:\no\existe.txt -ErrorAction Stop
}
catch [System.Management.Automation.ItemNotFoundException] {
    Write-Warning "El fichero no existe"
}
catch {
    Write-Error "Error inesperado: $($_.Exception.Message)"
}
finally {
    "Esto se ejecuta siempre"
}
  • Muchos cmdlets dan errores no terminantes: try/catch no los captura si no añades -ErrorAction Stop.
  • $Error[0] es el último error. En programas externos, comprueba $LASTEXITCODE.
