02¿Qué vamos a aprender? · Resultados de aprendizaje
RA1

Equipos microinformáticos y periféricos

Configurar equipos, componentes y periféricos analizando sus características, arquitectura, conexiones, prestaciones, diagnóstico y relación con el conjunto.
Resultado de aprendizaje del módulo. Pulsa de nuevo para contraer este apartado.
RA2

Software de propósito general

Instalar y evaluar software de uso general: utilidades, seguridad básica, ofimática, licencias, aplicaciones portables, mantenimiento e inventario.
Resultado de aprendizaje del módulo. Pulsa de nuevo para contraer este apartado.
RA3

Recuperación del software base

Trabajar con secuencias de arranque, particionado, creación y restauración de imágenes y diferentes soportes de almacenamiento.
Resultado de aprendizaje del módulo. Pulsa de nuevo para contraer este apartado.
RA4

Hardware específico de CPD

Analizar e implantar soluciones de centros de proceso de datos: hardware empresarial, almacenamiento, alimentación, seguridad física, condiciones ambientales e inventariado.
Resultado de aprendizaje del módulo. Pulsa de nuevo para contraer este apartado.
RA5

Prevención y protección ambiental

Aplicar normas de prevención de riesgos, seguridad, orden, limpieza, equipos de protección y gestión adecuada de residuos.
Resultado de aprendizaje del módulo. Pulsa de nuevo para contraer este apartado.

04Evaluación y calificación · Cómo se obtiene la nota

05Asistencia y evaluación continua · Límite de faltas

La asistencia forma parte del seguimiento ordinario del módulo. El alumnado que alcance o supere el 15% de faltas de asistencia perderá el derecho a la evaluación continua y deberá seguir el procedimiento previsto para la evaluación final.

Referencia: el 15% de 116 horas son 17,4 horas; como orientación práctica se presenta como aproximadamente 17 horas. La aplicación exacta se realizará conforme a la normativa y al registro de asistencia del centro.
06Convocatorias y recuperación · Qué ocurre con las partes pendientes
SituaciónCriterio general

2.ª convocatoria de junio (J2)La materia de la prueba abarcará el módulo completo y la superación se producirá al obtener la calificación mínima establecida.

07Redondeo de calificaciones · Cómo se obtiene la nota entera

La media de cada evaluación y la final se calcularán inicialmente con dos decimales. El resultado se redondeará al entero más próximo, con la excepción de las calificaciones iguales o superiores a 4,5 e inferiores a 5, que se mantendrán como 4.

Ejemplos: 5,60 → 6 · 5,40 → 5
Excepción: 4,70 → 4
08Autoría, plagio e inteligencia artificial · Integridad académica
Integridad académica: si una tarea, ejercicio, trabajo, práctica o examen ha sido copiado, plagiado o suplantado, total o parcialmente, podrá ser calificado como no apto / 0 para las partes implicadas.
  • El uso de herramientas de inteligencia artificial para realizar tareas o actividades evaluables no está permitido, salvo autorización expresa del profesor para una actividad concreta.
  • Las entregas deberán incluir las fuentes utilizadas y una bibliografía correctamente formateada, tomando como referencia APA 6.ª edición o superior.
  • La ausencia de citación adecuada podrá considerarse un problema de plagio o autoría.
  • Se valorarán la calidad, la originalidad, el trabajo propio y la capacidad de explicar o defender lo realizado.
