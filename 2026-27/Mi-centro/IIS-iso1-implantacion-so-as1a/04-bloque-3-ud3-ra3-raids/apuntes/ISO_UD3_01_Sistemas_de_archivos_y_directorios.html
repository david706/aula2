Sesión 01 · 1–2 h

Cómo organiza los datos un sistema operativo

RA3.a

Un sistema de archivos administra nombres, datos, metadatos, espacio libre, permisos y recuperación de estructuras. No confundirlo con la tabla de particiones ni con el soporte físico. El clúster o bloque es la unidad de asignación; guardar un fichero de 1 byte puede ocupar un bloque entero. El journaling anota operaciones para recuperar coherencia tras un apagado, no conserva versiones de los archivos.

En Linux el inodo almacena atributos y referencias a bloques; el directorio asocia nombres a inodos. En NTFS, la MFT registra los archivos y sus atributos. Los nombres son sensibles a mayúsculas habitualmente en Linux, mientras Windows generalmente no los distingue.

Un enlace duro es otro nombre del mismo objeto, normalmente dentro del mismo sistema de archivos; un enlace simbólico apunta a una ruta y puede quedar roto. Un acceso directo .lnk de Windows no equivale exactamente a un enlace simbólico.

mkdir -p ~/iso-ra3/enlaces
cd ~/iso-ra3/enlaces
echo "inventario" > original.txt
ln original.txt duro.txt
ln -s original.txt simbolico.txt
ls -li
mv original.txt renombrado.txt
ls -l; cat duro.txt; cat simbolico.txt
command -v ls
ls -l /bin /sbin /lib
find /etc -maxdepth 2 -name '*.conf' 2>/dev/null
dpkg -l | head

En Windows: where.exe notepad, Get-Command Get-Volume, Get-ChildItem $env:USERPROFILE. Examina Aplicaciones instaladas, msinfo32 y Visor de eventos sin cambiar el registro.
