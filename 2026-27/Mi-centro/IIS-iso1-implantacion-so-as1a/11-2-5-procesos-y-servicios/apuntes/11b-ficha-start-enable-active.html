start, enable, active: ¿en qué se diferencian?

Ficha para proyectar · Prueba el simulador y observa los dos indicadores.

Dos preguntas distintas

PreguntaLinux
ACTIVO¿Corre ahora mismo?systemctl is-active x
HABILITADO¿Arrancará al reiniciar?systemctl is-enabled x

Cada comando cambia una de las dos cosas (salvo --now, que cambia las dos).

Qué cambia cada comando

ComandoAhoraAl reiniciar

Simulador

¿CORRE AHORA?—
¿ARRANCARÁ AL REINICIAR?—

Las cuatro combinaciones

AhoraHabilitadoAl reiniciar…
activosívuelve a arrancar
activonono vuelve
paradosívuelve
paradonono arranca

La fila resaltada es el estado actual del simulador.

Cómo se demuestra de verdad

sudo systemctl disable --now apache2
systemctl is-enabled apache2   # disabled
sudo reboot
systemctl is-active apache2    # inactive
ss -tlnp | grep :80            # (vacío)

Solo reiniciando se comprueba lo que promete «habilitado». Tras el reinicio se pega la salida en la práctica.

start cambia lo que pasa ahora · enable cambia lo que pasará al reiniciar · y se comprueba reiniciando.
