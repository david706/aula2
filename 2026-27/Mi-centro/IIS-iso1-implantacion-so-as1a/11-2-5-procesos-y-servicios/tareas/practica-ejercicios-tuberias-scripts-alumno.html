5. Chuleta: if, for y while en Bash y en BAT

BASH 
#!/bin/bash
# variables y lectura
nombre="Ana"
read -p "Número: " n
echo "Hola $nombre, has puesto $n"
echo "Primer argumento: $1  Total: $#"

# if  (espacios dentro de [ ] obligatorios)
if [ "$n" -gt 10 ]; then
    echo "mayor que 10"
elif [ "$n" -eq 10 ]; then
    echo "es 10"
else
    echo "menor"
fi

# for sobre una lista, un rango o ficheros
for dep in contabilidad almacen; do
    echo "$dep"
done
for i in {1..5}; do echo "$i"; done
for f in /etc/*.conf; do echo "$f"; done

# while: contador
i=1
while [ $i -le 5 ]; do
    echo "$i"
    i=$((i+1))
done

# while: leer un fichero línea a línea
while IFS=';' read -r a b c d; do
    echo "$a está en $b"
done < empleados.txt
NúmerosTextoFicheros
-eq -ne -lt -le -gt -ge= != -z (vacío)-f fichero · -d dir · -e existe

Cálculos: $((a+b)). Ejecutar: chmod +x s.sh y ./s.sh.

BAT 
@echo off
setlocal enabledelayedexpansion
rem variables y lectura
set nombre=Ana
set /p n=Numero:
echo Hola %nombre%, has puesto %n%
echo Primer argumento: %1

rem if
if %n% GTR 10 (
    echo mayor que 10
) else if %n% EQU 10 (
    echo es 10
) else (
    echo menor
)

rem for sobre una lista, un rango o ficheros
for %%d in (contabilidad almacen) do echo %%d
for /L %%i in (1,1,5) do echo %%i
for %%f in (C:\Windows\*.ini) do echo %%f

rem "while": no existe, se hace con goto
set i=1
:bucle
if %i% GTR 5 goto fin
echo %i%
set /a i+=1
goto bucle
:fin

rem leer un fichero linea a linea
for /f "tokens=1-4 delims=;" %%a in (empleados.txt) do (
    echo %%a esta en %%b
)
NúmerosTextoFicheros
EQU NEQ LSS LEQ GTR GEQ== · /i sin mayúsculasif exist f · if not exist

Cálculos: set /a r=a+b. En un .bat las variables del for llevan dos %%; en la consola, una.

La trampa de BAT: dentro de un bloque ( … ) las %var% se sustituyen una sola vez, antes de ejecutar el bloque. Si cambias una variable dentro de un for o un if y quieres ver su valor nuevo, activa setlocal enabledelayedexpansion y escríbela como !var!.

6. Scripts en Bash

BASH

Un fichero por ejercicio dentro de ~/practica_terminal. Empieza siempre por #!/bin/bash y pruébalo con datos correctos y incorrectos.

if

B1 · par_impar.sh fácil
  • Pide un número por teclado y dice si es par o impar.
  • Si lo que escribe no es un número, muestra un error por stderr y sale con exit 1.

Pista: $((n % 2)). Para comprobar que es un número: [[ "$n" =~ ^[0-9]+$ ]].

B2 · que_es.sh fácil
  • Recibe una ruta como argumento (./que_es.sh /etc).
  • Dice si es un fichero, un directorio o si no existe.
  • Si no le pasan argumento, muestra cómo se usa y sale con error.
B3 · usuario.sh medio
  • Pide un nombre de usuario y dice si existe en el sistema.
  • Si existe, muestra sus grupos y dice si pertenece al grupo sudo.

Pista: id usuario &>/dev/null devuelve éxito si existe; id -nG usuario | grep -qw sudo.

for

B4 · tabla.sh fácil
  • Recibe un número como argumento y muestra su tabla de multiplicar del 1 al 10 (7 x 3 = 21).
  • Guarda además la tabla en tabla_7.txt (el número que toque) con tee.
B5 · departamentos.sh fácil
  • Con un for sobre la lista contabilidad direccion almacen becarios, crea empresa/<departamento>.
  • Dentro de cada una crea un LEEME.txt con el texto «Carpeta del departamento X».
  • Al final muestra el árbol con ls -R empresa.
B6 · contar_conf.sh medio
  • Recorre todos los /etc/*.conf y escribe en informe_conf.txt una línea por fichero: nombre: N líneas.
  • Los que no se puedan leer no deben ensuciar la pantalla: sus errores van a errores.log.
  • Al terminar muestra los 5 ficheros con más líneas (tubería sobre el informe).
B7 · sueldos_dep.sh medio
  • Para cada departamento distinto de empleados.txt (sácalos con una tubería dentro del for), muestra cuántos empleados tiene.

Pista: for dep in $(cut -d';' -f2 empleados.txt | sort -u); do …

while

B8 · nominas.sh medio
  • Lee empleados.txt línea a línea con while read.
  • Muestra nombre (departamento): sueldo € y añade [ALTO] si cobra más de 2000.
  • Al final muestra la suma total de sueldos.
B9 · adivina.sh medio
  • Genera un número secreto del 1 al 10 ($((RANDOM % 10 + 1))).
  • Mientras no aciertes, pide otro número y dice «mayor» o «menor».
  • Al acertar, dice en cuántos intentos.
B10 · menu.sh medio
  • Bucle while con un menú: 1) fecha y hora, 2) usuarios conectados, 3) espacio en disco de /, 4) memoria libre, 5) salir.
  • Usa if/elif para elegir. Una opción no válida muestra un error y vuelve al menú.
B11 · numerar.sh medio
  • Un filtro: lee de stdin línea a línea y devuelve cada línea numerada (1: …).
  • Debe funcionar con cat empleados.txt | ./numerar.sh, con ./numerar.sh < empleados.txt y dentro de una tubería: grep almacen empleados.txt | ./numerar.sh > almacen.txt.

7. Scripts en BAT

BAT

Guárdalos en C:\practica_terminal y ejecútalos desde cmd. Empieza con @echo off.

if

W1 · par_impar.bat fácil
  • Pide un número con set /p y dice si es par o impar.
  • Si no escriben nada, muestra un error y sale con exit /b 1.

Pista: en un .bat el resto se escribe %%: set /a r=n %% 2.

W2 · que_es.bat fácil
  • Recibe una ruta como argumento (que_es.bat C:\Windows) y dice si es carpeta, fichero o no existe.
  • Sin argumento: muestra cómo se usa.

Pista: if exist "%~1\" (con la barra al final) solo es cierto para carpetas.

for

W3 · tabla.bat fácil
  • Recibe un número y muestra su tabla del 1 al 10 con for /L.
  • Guarda la tabla en tabla_N.txt.
W4 · departamentos.bat fácil
  • Con un for sobre contabilidad direccion almacen becarios crea empresa\<departamento> con su LEEME.txt.
  • Si la carpeta ya existe, no debe salir error (pista: if not exist o 2>nul).
  • Al final muestra el árbol con tree empresa /f.
W5 · nominas.bat medio
  • Con for /f lee empleados.txt y muestra nombre (departamento): sueldo, marcando [ALTO] si supera 2000.
  • Al final muestra la suma total (necesitarás !total!).

«while» con goto

W6 · adivina.bat medio
  • Número secreto del 1 al 10 con %random%. Bucle con goto hasta que aciertes, diciendo «mayor» o «menor» y contando intentos.
W7 · menu.bat medio
  • Menú que se repite: 1) fecha y hora, 2) usuario actual y equipo, 3) dirección IPv4, 4) procesos que más memoria usan… o lo que elijas, 5) salir.
  • Opción no válida: mensaje de error y vuelta al menú.

8. Reto final (Bash y BAT)

informe_departamento.sh y informe_departamento.bat:
  1. Pide un departamento por teclado (stdin). Debe funcionar también con echo almacen | ./informe_departamento.sh y echo almacen| informe_departamento.bat.
  2. Si el departamento no existe en empleados.txt, escribe el error en errores.log (añadiendo, con fecha) y termina con código de error.
  3. Si existe, recorre sus empleados sin repetidos y muestra nombre, ciudad y sueldo.
  4. Muestra el número de empleados y la suma de sueldos del departamento.
  5. Todo lo que sale en pantalla se añade también a informe_<departamento>.txt, con una cabecera con fecha.
