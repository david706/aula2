Red TCP/IP en el cliente Windows 11

Criterio de evaluación: RA2.d

Situación: el ordenador de la oficina de la Ferretería Aragón usa Windows 11. Debe tener IP fija en la red de la tienda, ver al servidor y al puesto Ubuntu del mostrador, y seguir saliendo a Internet.

Entrega: un PDF en la tarea de Aeducar (ver apartado «Qué entregas»).

Datos

Antes de empezar, guarda cómo está tu red ahora, por si tienes que volver atrás:

ipconfig /all > "$HOME\estado-inicial-red.txt"

No toques el adaptador «Ethernet» (NAT). Si pierdes Internet porque lo cambiaste por error, devuélvelo a automático en una Terminal (Administrador):

netsh interface ipv4 set address name="Ethernet" dhcp
netsh interface ipv4 set dnsservers name="Ethernet" dhcp

Misión 1 · Adaptador 2 y situación inicial

  1. Con la VM apagada: VirtualBox → Configuración → Red → Adaptador 2 → Habilitar → Red interna → ferreteria.
  2. Arranca y ejecuta ipconfig /all. Identifica qué adaptador es el NAT y cuál el interno. Anota la IP que tiene el interno y explica qué es.

Misión 2 · IP fija con la interfaz gráfica

Configuración → Red e Internet → Ethernet → Ethernet 2 → Asignación de IP → Editar → Manual → IPv4. Pon los datos de la tabla. Deja la puerta de enlace vacía.

Misión 3 · Lo mismo por comandos

Ahora demuestra que sabes hacerlo sin ratón. Abre Terminal (Administrador), vuelve el adaptador a DHCP y configúralo de nuevo con netsh:

netsh interface ipv4 set address name="Ethernet 2" dhcp
netsh interface ipv4 set dnsservers name="Ethernet 2" dhcp
ipconfig                                   # debe volver a 169.254.x.x
netsh interface ipv4 set address name="Ethernet 2" static 192.168.100.51 255.255.255.0
netsh interface ipv4 set dnsservers name="Ethernet 2" static 8.8.8.8 primary
netsh interface ipv4 add dnsservers name="Ethernet 2" 8.8.4.4 index=2
netsh interface ipv4 show config name="Ethernet 2"

Si tu adaptador tiene otro nombre, cópialo de Get-NetAdapter.

Misión 4 · Permitir el ping desde la red de la tienda

netsh advfirewall firewall add rule name="Ping ferreteria" protocol=icmpv4:8,any dir=in action=allow remoteip=192.168.100.0/24

Desde el Ubuntu Desktop comprueba que ahora Windows responde: ping -c 4 192.168.100.51.

Misión 6 · Generar el archivo de evidencias

Después de reiniciar, abre Terminal (Administrador) con PowerShell, pega este bloque entero y pulsa Intro. Genera red_windows_<equipo>.txt en tu carpeta de usuario:

$f = "$HOME\red_windows_$env:COMPUTERNAME.txt"
$r = & {
"##### CABECERA"; whoami; hostname; Get-Date -Format "yyyy-MM-dd HH:mm:ss"
"##### W1 ADAPTADORES"; Get-NetAdapter | Format-Table Name,InterfaceDescription,Status,MacAddress -AutoSize
"##### W2 IPCONFIG"; ipconfig /all
"##### W3 IPV4"; Get-NetIPAddress -AddressFamily IPv4 | Format-Table InterfaceAlias,IPAddress,PrefixLength,PrefixOrigin -AutoSize
"##### W4 RUTAS"; route print -4
"##### W5 DNS"; Get-DnsClientServerAddress -AddressFamily IPv4 | Format-Table InterfaceAlias,ServerAddresses -AutoSize
"##### W6 PING_LAN"; ping -n 4 192.168.100.10; ping -n 4 192.168.100.50
"##### W7 PING_INTERNET"; ping -n 4 8.8.8.8
"##### W8 NSLOOKUP"; cmd /c "nslookup google.com 2>&1"
"##### W9 FIREWALL"; netsh advfirewall firewall show rule name="Ping ferreteria"
"##### W10 ARRANQUE"; (Get-CimInstance Win32_OperatingSystem).LastBootUpTime
"##### FIN"
} | Out-String -Width 200
$r; $r | Out-File -FilePath $f -Encoding utf8; "Guardado en $f"

No edites el archivo generado. Si algo sale mal, corrige y vuelve a ejecutar el bloque completo.
