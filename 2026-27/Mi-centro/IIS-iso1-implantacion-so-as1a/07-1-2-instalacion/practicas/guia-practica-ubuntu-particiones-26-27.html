Instalación de Ubuntu Linux y particionado dual / avanzado

Práctica guiada de configuración de máquina virtual, particionado manual avanzado y comprobación desde terminal, preparando el disco para una simulación de arranque dual.

Módulo
Implantación de Sistemas Operativos
Curso
1.º ASIR — 26/27
Unidades
UD1 – UD3

Objetivos de la práctica

  • 1Configurar una máquina virtual en VirtualBox optimizada para Linux Ubuntu.
  • 2Realizar la instalación de Ubuntu Linux mediante particionado manual avanzado (separando la raíz /, /home y la memoria de intercambio swap).
  • 3Preparar el disco virtual para la convivencia o simulación de sistemas duales (Dual-Boot), dejando espacio reservado o particiones compartidas (FAT32/NTFS).
  • 4Administrar particiones y montaje desde la terminal de Ubuntu mediante los comandos lsblk, fdisk, df -h y edición de /etc/fstab.

Configura una nueva máquina virtual con los parámetros técnicos requeridos para albergar Ubuntu Desktop y permitir el particionado avanzado.

FASE 2

Esquema de particionado manual en el instalador

Inicia la ISO de Ubuntu. Al llegar a la pantalla de Tipo de instalación, selecciona «Más opciones» / «Instalación personalizada» para crear la siguiente estructura de particiones.

/dev/sda1
Primaria · ext4
30 000 MB (30 GB)
Punto de montaje: /
Sistema operativo y binarios del kernel.
/dev/sda2
Lógica · ext4
25 000 MB (25 GB)
Punto de montaje: /home
Archivos personales y datos de usuarios.
/dev/sda3
Lógica · swap
4096 MB (4 GB)
Área de intercambio
Memoria virtual para suspensión/carga.
/dev/sda4
Primaria · FAT32/NTFS
20 000 MB (20 GB)
Punto de montaje: /media/compartido
Partición compartida para simulación Dual-Boot / Windows.
FASE 3

Comprobación y gestión de particiones desde terminal

Una vez completada la instalación e iniciado el sistema en Ubuntu, abre la terminal (Ctrl + Alt + T) y ejecuta los siguientes comandos obligatorios para documentar tu práctica.

# 1. Listar dispositivos de almacenamiento y puntos de montaje $ lsblk -f # 2. Comprobar el espacio libre y sistemas de archivos montados $ df -h -T # 3. Inspeccionar la tabla de particiones del disco con fdisk $ sudo fdisk -l /dev/sda # 4. Crear un directorio y montar automáticamente la partición compartida $ sudo mkdir -p /media/datos_compartidos $ sudo mount /dev/sda4 /media/datos_compartidos
