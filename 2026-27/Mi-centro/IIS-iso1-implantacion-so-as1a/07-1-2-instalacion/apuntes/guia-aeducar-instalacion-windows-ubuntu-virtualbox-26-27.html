ISO · 0369 1.º ASIR Curso 26/27 VirtualBox · Windows 11 · Ubuntu

Guía práctica de instalación de sistemas operativos

Una guía paso a paso para preparar máquinas virtuales, instalar Windows 11 y Ubuntu, practicar el particionado y realizar las comprobaciones básicas desde consola.

Cómo usar esta guía

Trabaja por bloques y guarda evidencias

Abre cada bloque únicamente cuando llegues a esa parte de la práctica. No se trata solo de “conseguir que arranque”: debes ser capaz de explicar qué has configurado, por qué y cómo comprobarlo.

1. Preparar

Crear correctamente la máquina virtual, asignar recursos y conectar la ISO.

2. Instalar

Completar la instalación de Windows 11 y Ubuntu siguiendo decisiones justificadas.

3. Comprobar

Usar comandos del sistema para demostrar que la instalación funciona.

4. Documentar

Guardar las capturas y explicaciones indicadas al final de cada bloque.

Bloque 0 · Antes de empezar

Material necesario
  • Oracle VirtualBox instalado.
  • ISO de Windows 11.
  • ISO de Ubuntu Desktop.
  • Espacio suficiente en disco para crear las máquinas virtuales.
  • Carpeta de trabajo para guardar capturas y documentación.
Consejo: nombra las máquinas virtuales de forma clara. Por ejemplo: ISO_Win11_2627 y ISO_Ubuntu_2627.
Qué debes aprender realmente
  • Diferenciar hardware físico y hardware virtual.
  • Asignar RAM, CPU y almacenamiento a una máquina virtual.
  • Entender el papel de EFI/UEFI y TPM en Windows 11.
  • Distinguir una instalación automática de un particionado manual.
  • Identificar particiones, sistemas de archivos y puntos de montaje en Linux.
  • Realizar comprobaciones básicas con terminal y CMD.

1.3 Crear una cuenta local durante OOBE

Cuando Windows entre en la fase OOBE y solicite conexión o cuenta Microsoft, prueba los métodos indicados por el profesor.

Método A · OOBE\BYPASSNRO

1
Abre CMD con Shift + F10 o Fn + Shift + F10.
C:\> OOBE\BYPASSNRO

Tras el reinicio, busca la opción para continuar sin conexión y crear una cuenta local.

Método B · Interfaz local directa

C:\> start ms-cxh:localonly

Método C · Creación manual desde consola

C:\> net user "AlumnoISO" "Password123" /add C:\> net localgroup Administradores "AlumnoISO" /add C:\> cd oobe C:\> msoobe.exe && shutdown -r -t 0
Importante: anota qué método has utilizado y qué ha ocurrido. Si un método no funciona, eso también forma parte de la práctica: documenta el mensaje o comportamiento observado.
1.4 Comprobaciones en Windows 11

Una vez dentro del escritorio abre CMD y realiza estas comprobaciones:

C:\> whoami C:\> net user AlumnoISO C:\> slmgr.vbs /dli
  • Identifica el usuario con el que has iniciado sesión.
  • Comprueba que la cuenta local existe.
  • Comprueba el estado de licencia mostrado por Windows.
  • Anota si la instalación aparece activada, sin activar o en periodo de gracia.

2.2 Particionado manual

Durante la instalación selecciona la opción de particionado manual o instalación personalizada y crea una estructura equivalente a la siguiente:

ParticiónTamañoSistema / montaje
/dev/sda130 GBext4 · /
/dev/sda225 GBext4 · /home
/dev/sda34 GBswap
/dev/sda420 GBFAT32/NTFS · espacio compartido
Pregunta de control: ¿por qué puede ser útil separar /home de la partición raíz /?
Evidencia U2: captura del esquema de particiones antes de confirmar los cambios.
2.3 Comprobaciones desde terminal

Cuando Ubuntu esté instalado abre una terminal con Ctrl + Alt + T.

$ lsblk -f $ df -h -T $ sudo fdisk -l /dev/sda

Después crea un punto de montaje y monta la partición compartida:

$ sudo mkdir -p /media/datos_compartidos $ sudo mount /dev/sda4 /media/datos_compartidos
  • Localiza qué partición corresponde a /.
  • Localiza la partición montada en /home.
  • Comprueba que existe el área swap.
  • Comprueba que la partición compartida está montada.
