1¿Qué es Docker?

Docker permite ejecutar aplicaciones dentro de entornos aislados llamados contenedores. El contenedor incluye la aplicación y sus dependencias, pero comparte el núcleo del sistema operativo anfitrión.

ConceptoExplicación sencillaEjemplo
ImagenPlantilla preparada para crear contenedores.nginx:alpine
ContenedorAplicación creada a partir de una imagen.web-dam
PuertoPermite acceder desde fuera al servicio.8080:80
VolumenConserva datos fuera del contenedor.portainer_data
RegistroLugar desde el que descargamos imágenes.Docker Hub
Idea clave: una imagen es la plantilla; un contenedor es una instancia de esa plantilla funcionando.

Docker frente a una máquina virtual

Máquina virtualContenedor
Incluye un sistema operativo completo.Comparte el núcleo de Linux con el anfitrión.
Suele consumir más RAM y disco.Suele arrancar rápido y consumir menos recursos.
Aislamiento a nivel de máquina.Aislamiento a nivel de procesos.

2Instalar Docker en Ubuntu 24.04

sudo apt update
sudo apt install docker.io docker-compose-v2 -y
sudo systemctl enable --now docker

Añadimos nuestro usuario al grupo Docker:

sudo usermod -aG docker "$USER"
newgrp docker

Comprobamos:

docker --version
docker compose version
systemctl is-active docker
systemctl is-enabled docker

Los dos últimos comandos deben mostrar active y enabled.

Si aparece “permission denied”: cierra la sesión de Ubuntu, vuelve a entrar y repite el comando. No soluciones permanentemente el problema utilizando siempre sudo docker.

3Instalar Docker en Windows 11

En Windows utilizaremos Docker Desktop con WSL 2. WSL 2 proporciona el núcleo Linux que necesitan los contenedores Linux. Después, los comandos de Docker y Compose son prácticamente iguales que en Ubuntu.

3.1 Requisitos

  • Windows 11 de 64 bits actualizado.
  • Virtualización Intel VT-x o AMD-V habilitada en BIOS/UEFI.
  • WSL 2 actualizado.
  • Al menos 8 GB de RAM; es preferible disponer de 16 GB.
Si Windows está dentro de VirtualBox: Docker Desktop necesita virtualización anidada. Para la práctica principal utilizaremos Ubuntu Server 24.04 en la MV; Windows se plantea como alternativa para un equipo físico.

3.2 Instalar WSL 2

Abre PowerShell como administrador:

wsl --install
wsl --update
wsl --status

Reinicia Windows cuando lo solicite. Si instala Ubuntu dentro de WSL, crea el usuario y la contraseña Linux al abrirlo por primera vez.

3.3 Instalar Docker Desktop

  1. Descarga Docker Desktop desde la documentación oficial.
  2. Ejecuta el instalador y selecciona el motor basado en WSL 2.
  3. Abre Docker Desktop y espera hasta que indique que el motor está funcionando.
  4. En Settings → General, comprueba que está activo el motor WSL 2.

3.4 Comprobar desde PowerShell

docker version
docker compose version
docker run --name saludo-windows hello-world
docker ps -a

Para ejecutar Nginx desde Windows:

docker run -d --name web-windows -p 8080:80 nginx:alpine

Abre http://localhost:8080. Después practica:

docker stop web-windows
docker start web-windows
docker logs web-windows
docker rm -f web-windows
Comprobación: compara la salida de los comandos en PowerShell y en Ubuntu. La sintaxis básica es la misma porque en ambos casos hablamos con el motor de Docker.

4Primera imagen y primer contenedor

Descargamos la imagen de prueba:

docker pull hello-world

Mostramos las imágenes disponibles:

docker images

Creamos y ejecutamos el contenedor:

docker run --name saludo hello-world

Comprobamos los contenedores:

docker ps
docker ps -a
Piensa: saludo aparece en docker ps -a, pero no en docker ps. La razón es que su tarea termina después de mostrar el mensaje.

5Un contenedor que permanece activo

docker run -d \
  --name web-dam \
  -p 8080:80 \
  nginx:alpine
ElementoSignificado
-dEjecuta el contenedor en segundo plano.
--name web-damAsigna un nombre al contenedor.
-p 8080:80Conecta el puerto 8080 de la MV con el 80 de Nginx.
nginx:alpineImagen utilizada.

Prueba en el navegador:

http://IP-DE-LA-MV:8080

Practica el ciclo de vida:

docker ps
docker stop web-dam
docker ps -a
docker start web-dam
docker logs web-dam
docker restart web-dam

Entramos temporalmente en el contenedor:

docker exec -it web-dam sh
ls /usr/share/nginx/html
exit

Al terminar:

docker stop web-dam
docker rm web-dam
docker rm elimina el contenedor, pero no la imagen. Puedes comprobarlo de nuevo con docker images.

6Primer proyecto con Docker Compose

Compose permite describir uno o varios servicios en un archivo compose.yaml y levantarlos con un solo comando.

Crear los archivos en Windows

Desde PowerShell:

mkdir "$HOME\docker-hola"
cd "$HOME\docker-hola"
notepad index.html
notepad compose.yaml

Guarda en esos archivos los mismos contenidos que aparecen a continuación. Los comandos docker compose posteriores son iguales en Windows y Ubuntu.

mkdir -p ~/docker-hola
cd ~/docker-hola
nano index.html

Contenido de index.html:

<!doctype html>
<html lang="es">
<meta charset="utf-8">
<title>Hola Docker</title>
<h1>Hola mundo desde Docker Compose</h1>
<p>Alumno/a: nombre y apellidos</p>

Ahora creamos:

nano compose.yaml

Contenido:

services:
  web:
    image: nginx:alpine
    container_name: hola-compose
    restart: unless-stopped
    ports:
      - "8080:80"
    volumes:
      - ./index.html:/usr/share/nginx/html/index.html:ro

Validamos y arrancamos:

docker compose config
docker compose up -d
docker compose ps
docker compose logs --tail=20

Abre http://IP-DE-LA-MV:8080.

ComandoAcción
docker compose up -dCrea e inicia el proyecto.
docker compose stopDetiene sin eliminar.
docker compose startArranca de nuevo.
docker compose downDetiene y elimina contenedor y red.
Prueba de rearranque: en Ubuntu ejecuta sudo reboot; en Windows, reinicia desde el menú Inicio y vuelve a abrir Docker Desktop si no se inicia automáticamente. Después comprueba con docker ps que la web ha arrancado gracias a restart: unless-stopped.

7Conocer Portainer

Portainer es una interfaz web para visualizar y administrar Docker. No sustituye los comandos: permite ver gráficamente las imágenes, contenedores, volúmenes, redes y registros.

docker volume create portainer_data

docker run -d \
  --name portainer \
  --restart=always \
  -p 9443:9443 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v portainer_data:/data \
  portainer/portainer-ce:lts
Comando equivalente en Windows PowerShell

Con Docker Desktop iniciado, ejecuta:

docker volume create portainer_data
docker run -d --name portainer --restart=always -p 9443:9443 -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer-ce:lts

Después abre https://localhost:9443.

Acceso:

https://IP-DE-LA-MV:9443
  1. Acepta el certificado autofirmado solamente en la red privada del laboratorio.
  2. Crea el usuario administrador.
  3. Selecciona el entorno local.
  4. Localiza hola-compose y portainer.
  5. Abre los registros del contenedor web.
Seguridad: montar /var/run/docker.sock permite a Portainer administrar todo Docker. Solo debe acceder personal autorizado.

8Reto final

  1. Cambia el texto de la página y añade tu grupo.
  2. Cambia el puerto exterior de 8080 a 8081.
  3. Ejecuta docker compose up -d.
  4. Comprueba la web con curl http://localhost:8081.
  5. Localiza el nuevo puerto desde Portainer.
  6. Explica oralmente la diferencia entre imagen, contenedor y archivo Compose.

Evidencias

  • Salida de docker images.
  • Salida de docker ps.
  • Contenido de compose.yaml.
  • Web funcionando en el puerto 8081.
  • Portainer mostrando ambos contenedores.

Chuleta mínima

docker pull IMAGEN             # Descargar imagen
docker images                  # Listar imágenes
docker run ... IMAGEN          # Crear y ejecutar
docker ps                      # Contenedores activos
docker ps -a                   # Todos los contenedores
docker stop NOMBRE             # Detener
docker start NOMBRE            # Iniciar
docker logs -f NOMBRE          # Ver registros
docker exec -it NOMBRE sh      # Entrar
docker rm NOMBRE               # Eliminar contenedor
docker compose up -d           # Levantar proyecto
docker compose ps              # Ver servicios
docker compose down            # Retirar proyecto
