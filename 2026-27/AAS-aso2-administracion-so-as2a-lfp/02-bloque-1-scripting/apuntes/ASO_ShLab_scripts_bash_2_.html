Chuleta de Bash


Estructura y ejecución


#!/bin/bash
# Comentario
echo "Hola mundo"
exit 0


OrdenQué hace


#!/bin/bashShebang: primera línea, indica el intérprete.


chmod +x script.sh · ./script.shDa permiso de ejecución · lo ejecuta.


bash -x script.sh · bash -n script.shEjecuta mostrando cada orden (depurar) · solo comprueba la sintaxis.


exit N · $?Termina con el código N (0 = bien) · código de la última orden.



Variables


SintaxisQué hace


nombre="Ana"Crea una variable. Sin espacios junto al = (a = 5 intenta ejecutar la orden a).


$nombre · ${nombre} · "$nombre"Lee el valor. Entre comillas dobles se conservan los espacios.


'$nombre'Comillas simples: texto literal, no se sustituye nada.


$(orden)Sustitución de órdenes: la salida de la orden.


$(( a + b * 2 )) · (( i++ )) · let x=a+1Aritmética entera (+ - * / % **).


read -p "Edad: " edadLee del teclado.


$USER $HOME $PWD $RANDOMVariables de entorno útiles.


${#s} ${s:0:3} ${s%.*} ${s##*.} ${v:-defecto}Longitud, subcadena, quitar extensión, extensión, valor por defecto.


a=(uno dos) · ${a[0]} · ${a[@]} · ${#a[@]}Arrays: crear, un elemento, todos, número de elementos.



Parámetros


SintaxisSignificado


$0 · $1 … $9 · ${10}Nombre del script · parámetros.


$#Número de parámetros.


"$@" · $*Todos los parámetros ("$@" respeta los que llevan espacios).


shiftDesplaza los parámetros.



Condiciones


if [ $# -eq 0 ]; then
    echo "Falta el parametro"
    exit 1
elif [ "$1" -ge 18 ]; then
    echo "Mayor"
else
    echo "Menor"
fi
[ -f notas.txt ] && echo "Existe" || echo "No existe"


OperadorSignificado


-eq -ne -lt -le -gt -geComparan números: = ≠ < ≤ > ≥.


= != -z -nComparan textos · vacío · no vacío.


-f -d -e -r -w -xEs fichero · es directorio · existe · se puede leer / escribir / ejecutar.


! -a -o · && ||No · y · o (dentro de [ ]) · y · o (entre órdenes o en [[ ]]).


[[ $f == *.txt ]] · (( n > 5 ))Patrones en [[ ]] · comparación aritmética en (( )).


Dentro de [ ] hacen falta espacios: [ $a -gt 5 ]. Pon las variables entre comillas ("$a") para que no falle si están vacías.

Bucles


FormaQué recorre


for x in uno dos tres; do echo $x; doneUna lista de valores.


for f in *.txt; do echo "$f"; doneFicheros que cumplen el patrón (si no hay ninguno, $f vale *.txt).


for i in $(seq 1 10) · for i in {1..10} · for ((i=1;i<=10;i++))Contadores.


while [ $n -lt 5 ]; do ... done · until ...Mientras se cumpla · hasta que se cumpla.


while IFS=';' read -r a b; do ... done < datos.csvLee un fichero línea a línea, partida en campos.


break · continueSale del bucle · pasa a la siguiente vuelta.


Una tubería (cat f | while read ...) ejecuta el bucle en un subproceso: las variables que cambies dentro se pierden al terminar. Usa done < fichero.



Funciones


saluda() {
    local nombre=$1
    echo "Hola, $nombre"
    return 0
}
saluda Ana


Se definen antes de usarlas. Los argumentos llegan como $1, $2… Para devolver un valor se muestra con echo y se recoge con $(funcion); return solo devuelve un código.

Ayuda


Cómo funciona. Elige un ejercicio, escribe tu script en el editor y pulsa Ejecutar. Si usa parámetros ($1, $2…), escríbelos en Parámetros. Si lee del teclado con read, pon las respuestas en Entrada de teclado, una por línea.


Traza. Ejecutar con traza equivale a bash -x: muestra en gris cada orden con las variables ya sustituidas. Es la mejor forma de encontrar errores.


Comprobar. Pasa varias pruebas automáticas (distintos parámetros, entradas y ficheros). El ejercicio queda superado cuando pasan todas. Solo se compara la salida normal; los mensajes de error aparecen en rojo para que los leas.


Atajos. Ctrl + Intro ejecuta. La tecla Tab inserta 4 espacios.
